# Proxy Manager Tool Releases

Release artifacts (Windows `.exe`) for **NetAgent.ProxyManager**, published here so
`homeproxy-resell`'s `/tool-proxy` download page can always fetch the latest build
automatically via the GitHub Releases API.

This repo intentionally holds no source code — see the app's own repository for that.
Publish a new release here (tag + upload the `.exe` as a release asset, marked
"Set as the latest release") whenever a new build should go live to customers.
